# 简单FAT虚拟文件系统实验说明

## 1. 文件系统介绍
本项目实现了一个基于FAT的简化单用户文件系统，支持多级目录、文件创建/删除、打开/关闭、读写与持久化。虚拟磁盘以单一镜像文件保存，程序启动时自动加载镜像，退出时写回。

核心特性：
- 1MB虚拟磁盘（1024块，每块1KB）
- FAT链式分配
- inode表保存元数据（名称、大小、父目录、起始块等）
- 目录使用子项索引列表
- 文件读写使用文件指针（偏移）

## 2. 代码文件说明
- [fs.h](fs.h) 头文件，定义常量、数据结构与函数声明
- [fs.c](fs.c) 文件系统核心实现：FAT管理、目录/文件操作、读写与持久化
- [main.c](main.c) 交互式命令行入口，解析命令并调用文件系统接口
- [vdisk.img](vdisk.img) 虚拟磁盘镜像文件（首次格式化后生成）
- [myfs](myfs) 编译生成的可执行程序

## 3. 编译与运行命令
在项目目录下执行：

```bash
gcc -std=c11 -O2 -Wall -Wextra -o myfs main.c fs.c
./myfs
```

## 4. 命令说明
- `my_format` 格式化虚拟磁盘，初始化FAT和根目录
- `my_mkdir <name>` 创建目录
- `my_rmdir <name>` 删除空目录
- `my_ls` 列出当前目录内容
- `my_cd <name|..|/>` 切换目录（支持..返回上级，/回到根）
- `my_create <name>` 创建文件
- `my_rm <name>` 删除文件（文件不能处于打开状态）
- `my_open <name>` 打开文件，返回fd
- `my_close <fd>` 关闭文件
- `my_write <fd> <text>` 从当前文件指针写入文本
- `my_read <fd> <len>` 从当前文件指针读取指定长度
- `my_exit` 保存镜像并退出

## 5. 命令示例与解释
以下示例均为交互式输入：

- `my_format`
	初始化磁盘并创建根目录。首次使用前必须执行。
- `my_mkdir dir1`
	在当前目录下创建名为 `dir1` 的子目录。
- `my_rmdir dir1`
	删除空目录 `dir1`。如果目录内有子项会失败。
- `my_ls`
	列出当前目录内容，例如输出 `a.txt 11` 表示文件大小为 11 字节。
- `my_cd dir1`
	进入目录 `dir1`。
- `my_cd ..`
	返回上一级目录。
- `my_cd /`
	返回根目录。
- `my_create a.txt`
	在当前目录创建空文件 `a.txt`。
- `my_open a.txt`
	打开文件并返回文件描述符，例如输出 `fd=0`。
- `my_close 0`
	关闭文件描述符 0。
- `my_write 0 hello_world`
	从当前文件指针写入文本，写入后指针后移。
- `my_read 0 5`
	从当前文件指针读取 5 字节并输出。
- `my_rm a.txt`
	删除文件 `a.txt`，若文件仍处于打开状态会失败。
- `my_exit`
	保存磁盘镜像并退出程序。
